How evidence works discipline of citation

Each EvidenceItem node in the graph holds:

  • subdomain_id — ONE AEGIS sub-domain (D-XX.Y)
  • scale — coverage (Scale B) or capability (Scale A)
  • outcome — a regulatory clause id (Coverage) or a CSF/PF subcategory (Capability)
  • claim — one-sentence observable fact; never a Tier number
  • sources[] — ≥1 graph node IDs. empty ⇒ Gate 3 FAIL
  • observed — true (present) or false (declared gap)

The two radars above visualise Scale A across both overlays. The tier-bar shows the same data as a horizontal segment strip. The Coverage table (below) shows Scale B, anchored on GDPR/CRA clauses — and now also lists the PF anchor from OVERLAY_NIST_PF_1.1.md §2.
